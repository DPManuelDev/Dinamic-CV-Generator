# CV Builder React

Migração do projeto original de HTML/CSS/JavaScript para React.

## Funcionalidades
- 4 templates: Clássico, Moderno, Minimalista e Criativo
- Seleção das seções que aparecem no CV
- Dados pessoais
- Fotografia
- Resumo profissional
- Experiência profissional dinâmica
- Formação académica dinâmica
- Habilidades
- Idiomas
- Certificados
- Projetos
- Preview em tempo real
- Escolha de cor de destaque
- Exportação para PDF A4

## Instalação

```bash
npm install
npm run dev
```

Abra o endereço mostrado pelo Vite, normalmente `http://localhost:5173`.

## Build

```bash
npm run build
```

## Observação

A pasta `.git` do projeto original não foi incluída nesta migração. Depois de validar a nova versão, ela pode ser colocada no teu repositório GitHub com `git add`, `git commit` e `git push`.
